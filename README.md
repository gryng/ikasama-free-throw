# イカサマフリースロー

上にフリックしてシュート。ボールが空中にある間のスローモーション「イカサマタイム」に、ゴールをドラッグして好きな位置へ動かせるバスケのフリースローゲーム。ライフ3つ、3回ミスでゲームオーバー。

- ゴールを動かさずに決めると +2（動かして決めると +1）
- 連続で決めると3本ごとにコンボ倍率アップ（最大×4）
- プレイ内容で決まる称号（二つ名つき）と称号コレクション
- ゲームが終わると先輩がアドバイス

## ファイル

- `index.html` … ゲーム本体（GitHub Pages で公開するページ）
- `gas/Code.gs` … オンラインランキング用の Google Apps Script

## オンラインランキング

`gas/Code.gs` を Google スプレッドシートの Apps Script に貼り付け、ウェブアプリ（実行ユーザー: 自分 / アクセス: 全員）としてデプロイする。
発行された `…/exec` のURLを `index.html` の `const RANK_URL = '';` に入れる。
URLが空のときは仮データ（SAMPLE）で動く。

- ランキングは端末ごとのプレイヤーIDで「1人1件・最高スコア」
- 1点以上でゲームオーバーになると自動で登録
- 送られたスコアは、成功数から計算できる理論上の最高点を超えていないかサーバー側で確認する
